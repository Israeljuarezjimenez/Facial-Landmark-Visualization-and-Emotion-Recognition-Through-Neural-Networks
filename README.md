# Visualización y modelado de emociones

Este repositorio contiene únicamente los dos cuadernos que quiero subir a GitHub para compartir esta parte del proyecto.

## Cuadernos incluidos

- `notebooks/Visualización_emociones_p1.ipynb`
- `notebooks/redneuronal-Copy1 EL BUENO .ipynb`

## Nota importante

No se incluyen los datos originales, los modelos entrenados ni los archivos de salida generados.

La carpeta `Data/` se mantiene en el entorno local y queda ignorada por Git para evitar subir archivos pesados o sensibles.

## Requisitos

- Python 3.x
- Jupyter Notebook o JupyterLab
- Bibliotecas como:
  - pandas
  - numpy
  - matplotlib
  - seaborn
  - scikit-learn
  - torch

## Uso

1. Clona este repositorio.
2. Abre cualquiera de los dos cuadernos dentro de la carpeta `notebooks/`.
3. Si necesitas reproducir resultados, agrega los datos originales en tu entorno local.
