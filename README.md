# Visualización y modelado de emociones

Este repositorio contiene cuadernos de trabajo para análisis y visualización de emociones, así como experimentos de redes neuronales y modelos de clasificación.

## Contenido

- `notebooks/Visualización_emociones_p1.ipynb`
- `notebooks/redneuronal.ipynb`
- `notebooks/redneuronal-Copy1 EL BUENO .ipynb`
- `notebooks/RN.ipynb`
- `notebooks/SVM.ipynb`
- `notebooks/Práctica_RD.ipynb`
- `notebooks/Correlacion_pearson.ipynb`
- `notebooks/Reporte_correlación.ipynb`
- `notebooks/spearman.ipynb`

## Nota importante

Los archivos de datos, modelos entrenados y resultados generados no se incluyen en este repositorio para mantenerlo ligero y adecuado para subir a GitHub.

Se dejó una carpeta `Data/` en el entorno local, pero está ignorada por Git para evitar subir archivos pesados o sensibles.

## Requisitos

- Python 3.x
- Jupyter Notebook o JupyterLab
- Bibliotecas de análisis y visualización como:
  - pandas
  - numpy
  - matplotlib
  - seaborn
  - scikit-learn
  - torch

## Uso

1. Clona este repositorio.
2. Abre cualquiera de los cuadernos dentro de la carpeta `notebooks/`.
3. Agrega los datos originales en una ruta local si es necesario para reproducir los resultados.
